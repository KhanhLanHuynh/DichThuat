# Glossary — Thuật ngữ Phật giáo

Sổ đăng ký thuật ngữ Hán → Việt dùng chung. Ghi đè theo bộ kinh nằm trong `{series}.yaml`.

## File

| File | Phạm vi |
|------|---------|
| `terms.yaml` | Mặc định / xuyên bộ kinh |
| `{series}.yaml` | Ghi đè cho một bộ kinh |

## Cách dùng

Trước khi dịch, tra khóa `zh`. Thêm thuật ngữ mới trước lần dùng đầu trong bản dịch.

Chạy `/glossary-curator` hoặc skill **build-glossary** để điền từ nguồn.
