# Tài liệu tham khảo

Lưu tài liệu hỗ trợ:

- Bản dịch Việt trước đây (trích PDF, trích dẫn)
- Ghi chú từ điển (佛光大辭典, Soothill-Hodous, v.v.)
- Ghi chú ấn bản CBETA/Taishō
- Bài học thuật

Dùng thư mục con theo bộ kinh nếu cần: `references/{series}/`.

Không commit toàn văn có bản quyền nếu chưa được phép.
